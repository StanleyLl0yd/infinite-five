# Infinite Five Privacy Policy

_Last updated: September 1, 2026_

## English

Infinite Five is designed to work without an account, advertising, analytics or a developer-operated backend.

### Data handled by the application

Infinite Five does not collect or transmit personal data to the developer. The application stores the following game data locally on the user's device:

- current unfinished game;
- application settings;
- local game statistics;
- a bounded history of recent completed games.

This local data is used only to provide application functionality and remains on the device unless the user chooses to remove application data or uninstall the application.

### Sharing games

When the user explicitly chooses to share a game or replay, Infinite Five creates a link containing only the move coordinates needed to reconstruct that game. The application does not upload the replay to a developer server. The selected system sharing destination is controlled by the user and may have its own privacy policy.

### Permissions

The Android release requests vibration access only to provide optional haptic result feedback. The production application does not request network access or sensitive Android permissions.

### Third parties

Infinite Five contains no advertising, analytics or tracking SDKs. Store and operating-system services used to install, update or share the application operate under their own terms and privacy policies.

### Children

The application does not knowingly collect personal information from children or other users because it does not collect personal information from users at all.

### Changes

If application behavior changes in a way that affects data handling, this policy will be updated before or together with the relevant release.

### Contact

Privacy questions can be submitted through the public Infinite Five repository maintained by `StanleyLl0yd` on GitHub.

## Русский

Infinite Five разработана для работы без учётной записи, рекламы, аналитики и серверной инфраструктуры разработчика.

### Какие данные обрабатывает приложение

Infinite Five не собирает и не передаёт разработчику персональные данные. На устройстве пользователя локально сохраняются только данные, необходимые для функций приложения:

- текущая незавершённая партия;
- настройки приложения;
- локальная игровая статистика;
- ограниченная история последних завершённых партий.

Эти данные используются только для работы приложения и остаются на устройстве, пока пользователь самостоятельно не очистит данные приложения или не удалит приложение.

### Отправка партий

Когда пользователь самостоятельно выбирает функцию отправки партии или повтора, Infinite Five создаёт ссылку, содержащую только координаты ходов, необходимые для восстановления партии. Приложение не загружает повтор на сервер разработчика. Выбранное пользователем системное приложение или сервис для отправки может иметь собственную политику конфиденциальности.

### Разрешения

Android-версия запрашивает доступ к вибрации только для опционального виброотклика после завершения партии. Production-версия приложения не запрашивает доступ к сети или чувствительные разрешения Android.

### Сторонние сервисы

Infinite Five не содержит рекламных, аналитических или отслеживающих SDK. Магазин приложений и системные сервисы ОС, используемые для установки, обновления или отправки данных пользователем, работают по собственным условиям и политикам конфиденциальности.

### Дети

Приложение не собирает персональные данные детей или других пользователей, поскольку персональные данные пользователей приложением не собираются.

### Изменения политики

Если поведение приложения изменится таким образом, что это затронет обработку данных, настоящая политика будет обновлена до или одновременно с соответствующим релизом.

### Контакты

Вопросы по конфиденциальности можно направить через публичный репозиторий Infinite Five, который поддерживает `StanleyLl0yd` на GitHub.
