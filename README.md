# Infinite Five

Infinite Five is a five-in-a-row game on an infinite board, built as a responsive web application and PWA.

## Play

https://stanleyll0yd.github.io/infinite-five/

## Current implementation

- infinite Canvas board;
- computer opponent with Easy, Medium and Hard difficulty;
- local X vs O play;
- five-or-more win detection;
- AI-game undo;
- AI win/loss statistics;
- drag navigation;
- mouse-wheel and pinch zoom;
- latest-move highlight;
- winning-line highlight;
- unfinished-game persistence;
- light and dark themes;
- responsive desktop and mobile layout;
- PWA configuration;
- automated game-engine tests;
- GitHub Pages deployment.

## Development

```bash
npm install
npm run dev
```

Tests and production build:

```bash
npm test

```
